Fluent retries while idle callbacks have time remaining. A callback with no time remaining lets initialization complete, so a working accordion means the blocking condition was not sustained on this run. Reloading may produce a different result, but does not guarantee a failure.

For a repeatable demonstration, run npm test. Only the automated test supplies controlled idle deadlines; this page uses the browser’s real scheduler.
